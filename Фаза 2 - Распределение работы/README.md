# Фаза 2 (мета). Распределение работы

**Состояние: не начата.** Зависит от выбора концепции в фазе 1. Фазы 2 и 3 связаны: распределяются именно работы фазы 3.

## Требования задания

1. Разбить работу фазы 3 на задачи.
2. Оценить сложность или трудозатраты задач экспертным путём.
3. Собрать индивидуальные оценки предпочтительности задач от каждого участника.
4. Сформулировать и обосновать задачу распределения: целевую функцию и ограничения.
5. Решить её подходящим инструментом (OpenSolver, NEOS, Pyomo и т. п.).

LLM разрешена для помощи в кодинге (с обязательным пониманием кода) и для предложения формулировок задачи.

## Ожидаемые результаты

- Список задач фазы 3 с ID `P3-…` в [Задачах](<../Таск трекер/Задачи.md>): Use Cases, COSMIC, UCP, коллективная экспертная оценка, выводы, отчёт, встречи.
- Реальные оценки сложности от участников и индивидуальные предпочтения по каждой задаче.
- Постановка задачи о назначениях: переменные, целевая функция (например, предпочтения с учётом сложности), ограничения (каждая задача назначена, баланс нагрузки).
- Решение, проверка допустимости и обновлённая [Матрица RACI](<../Таск трекер/Матрица RACI.md>).

## Зависимости

- Фаза 1: выбранная концепция и решение команды.
- Требования фазы 3 — нужны для декомпозиции.
- Журнал работы фазы 1 — для учёта времени и недельной статистики фазы 4.
