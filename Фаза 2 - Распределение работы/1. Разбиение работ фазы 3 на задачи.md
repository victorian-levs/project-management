# 1. Разбиение работ фазы 3 на задачи

Фазы 2 и 3 связаны: в фазе 2 распределяются работы фазы 3 по выбранной концепции MusicApp. Поэтому сначала работа фазы 3 разбита на задачи, исходя из её требований: Use Cases, COSMIC, UCP, коллективная экспертная оценка, выводы и отчёт.

## Индивидуальные задачи (распределяются оптимизацией)

| ID | Задача | Результат | Зависит от |
|---|---|---|---|
| P3-02 | Описать UC-01–UC-05: учётная запись, поиск, исполнитель, воспроизведение | Спецификации UC с основными, альтернативными и негативными потоками | P3-01 |
| P3-03 | Описать UC-06–UC-10: избранное, плейлисты, публикация, подписки | То же | P3-01 |
| P3-04 | Описать UC-11–UC-14: история, подборка, администрирование каталога | То же | P3-01 |
| P3-05 | Диаграмма вариантов использования и сводный каталог UC | Диаграмма, проверка единообразия и границ сценариев | P3-02, P3-03, P3-04 |
| P3-06 | COSMIC: граница, функциональные пользователи, группы данных, процессы | Модель измерения | P3-05 |
| P3-07 | COSMIC: движения данных по процессам и итог в CFP | Таблица E/X/R/W, размер в CFP | P3-06 |
| P3-08 | UCP: акторы, сложность Use Cases по транзакциям, UUCP | Классификация акторов и UC | P3-05 |
| P3-09 | UCP: факторы TCF и ECF, UCP и трудозатраты | Расчёт UCP и трудозатрат | P3-08 |
| P3-10 | Подготовить коллективную экспертную оценку трудозатрат (форма, правила Дельфи) | Форма и регламент оценки | P3-05 |
| P3-11 | Свести экспертные оценки и агрегировать в оценку проекта | Согласованные оценки UC, итог проекта | P3-14 |
| P3-12 | Сравнить оценки, выводы о команде, сроке и сокращениях объёма | Раздел выводов | P3-07, P3-09, P3-11 |
| P3-13 | Отчёт по фазе 3 | Материалы фазы 3 в отчёте | P3-12, P3-15 |

## Совместные задачи (выполняют все трое)

| ID | Задача | Длительность на участника |
|---|---|---|
| P3-01 | Встреча: старт фазы 3, уточнение границ MVP и модели ролей | 1 ч |
| P3-14 | Встреча: экспертная оценка трудозатрат Use Cases (Дельфи, 2 тура) | 1,5 ч |
| P3-15 | Встреча: обсуждение выводов фазы 3 | 1 ч |

Встречи не распределяются: в них участвуют все. Индивидуальные экспертные оценки в P3-14 тоже даёт каждый участник, поэтому эта работа не может достаться одному человеку.

## Принципы разбиения

- Каждая задача даёт проверяемый результат и выполняется одним человеком.
- Use Cases разбиты на три блока близкого объёма по смыслу: доступ и прослушивание, личная библиотека, история и администрирование.
- Задачи одного метода (COSMIC: P3-06 и P3-07; UCP: P3-08 и P3-09) идут последовательно: вторая опирается на модель, построенную в первой.
