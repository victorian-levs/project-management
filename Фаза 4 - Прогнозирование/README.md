# Фаза 4 (мета). Прогнозирование

**Состояние: не начата.** Фазы 4 и 5 связаны: прогнозируется выполнение учебных работ фазы 5 по накопленной истории команды.

## Требования задания

1. Разбить работы фазы 5 на задачи.
2. Дать трёхточечные оценки времени выполнения этих задач.
3. Сделать прогноз методом Монте-Карло двумя способами:
   - по распределению числа задач, выполненных за неделю, — срок фазы 5 в неделях с достоверностью 80 %;
   - по распределению человеко-часов, которые команда выделяет в неделю, с длительностями задач из треугольного распределения, — срок с достоверностью 80 %.
4. Сравнить результаты двух моделей и объяснить различие.

LLM разрешена для помощи в кодинге.

## Ожидаемые результаты

- Учебные задачи фазы 5 (`P5-…`) с трёхточечными оценками.
- Две модели Монте-Карло, 80-й процентиль срока в каждой, сравнение и объяснение.

## Какие данные копятся уже сейчас

- [Журнал работы.csv](<../Таск трекер/Журнал работы.csv>) — чистое время участников по задачам.
- [Статистика по неделям.csv](<../Таск трекер/Статистика по неделям.csv>) — число завершённых задач и человеко-часы по неделям, включая недели с нулём.

Прогноз относится к реальной учебной работе трёх участников. 40-часовая неделя продуктового плана фазы 5 к ней не применяется.

## Зависимости

- История задач фаз 1–3 (журнал и недельная статистика).
- Декомпозиция учебных работ фазы 5.
