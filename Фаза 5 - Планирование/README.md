# Фаза 5. Планирование

**Состояние: не начата.** Планируется воображаемая разработка продукта, выбранного в фазах 1 и 3. Продукт в рамках предмета не разрабатывается.

## Требования задания

1. Разложить выполнение проекта на 20–25 задач.
2. По выводам фазы 3 указать состав команды по специальностям (разработчик, тестировщик, дизайнер и т. д.) — это типы ресурсов.
3. Для каждой задачи указать ресурсные требования и связи предшествования.
4. Решить задачу эвристиками упорядочения (SLK, FREE, LST, LFT, LSTLFT, GRPW, LPT, MIS, GRD, GRWC, GCRWC, ROT и случайные приоритеты) с помощью предоставленного кода и выбрать лучшее решение.
5. Перенести решение на 8-часовой рабочий день (40 часов в неделю) и определить плановые сроки проекта и этапов.

LLM разрешена для помощи в кодинге.

## Ожидаемые результаты

- Список продуктовых задач `D-01…D-25` с длительностями, ресурсами и предшествованием.
- Результаты эвристик, лучшее расписание, календарный план.

## Разделение учёта

Продуктовые задачи `D-…` — воображаемые работы команды разработки. Её роли и численность могут отличаться от трёх участников учебной команды. Эти задачи не входят в [Задачи](<../Таск трекер/Задачи.md>) и трудозатраты команды. Учебная работа по составлению плана учитывается отдельно, как задачи `P5-…`.

## Задел для MusicApp (если выбран)

Естественные группы работ для будущей декомпозиции: требования и UX, схема данных, авторизация, каталог и поиск, файлы и воспроизведение, избранное, плейлисты, подписки, история, подборка, интерфейс администратора, интеграция, тестирование, развёртывание. Разбиение на 20–25 задач и ресурсные оценки выполняются в этой фазе.

## Зависимости

- Фаза 3: Use Cases, оценки объёма, состав команды, возможные сокращения.
- Фаза 4: прогноз сроков учебных работ фазы 5.
