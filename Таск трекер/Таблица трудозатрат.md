# Таблица трудозатрат

Фактическое чистое время по участникам — только по данным самих участников из [Журнала работы](<Журнал работы.csv>). Пустая ячейка означает «не предоставлено». Время работы LLM-агента над материалами здесь не учитывается: учитывается работа людей.

Итог считается в человеко-часах: час совместной работы трёх участников — три человеко-часа. Здесь учитывается только учебная работа по предмету. Прошлые часы разработки MusicApp и воображаемые трудозатраты продукта из фазы 5 сюда не входят.

## Как заполнять

1. После каждого отрезка работы участник добавляет строку в `Журнал работы.csv`: дата, ID задачи, участник, начало, конец, чистые минуты (без перерывов), примечание, источник данных («личная запись», «трекер времени», «оценка по памяти» и т. п.).
2. Часы участника по задаче = сумма его чистых минут / 60.
3. Итого по задаче = сумма часов участников.
4. Задача считается выполненной, когда её статус в [Задачах](<Задачи.md>) — «выполнена». Неделя завершения задачи берётся по дате фактического окончания.

## Недельная статистика для фазы 4

Фаза 4 прогнозирует сроки фазы 5 по истории команды, поэтому с первой фазы ведётся [Статистика по неделям.csv](<Статистика по неделям.csv>): неделя, число завершённых задач, суммарные человеко-часы. В файл попадают все наблюдавшиеся недели, **включая недели с нулём**: они тоже часть распределения. Значения выводятся из журнала и статусов задач, вручную не придумываются.
