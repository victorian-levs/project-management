# Расчётный инструмент фазы 1

> Использовать для сдаваемой работы — только после ответа преподавателя о допустимости автоматических расчётов ([P1-11](<../../Таск трекер/Задачи.md>)). Если автоматизация не разрешена, методика из документов 3 и 4 выполняется вручную в Excel, а инструмент служит только для сверки.

Инструмент написан с помощью LLM. Команда должна уметь объяснить каждую стадию; стадии описаны в комментариях в начале `lib/topsis.mjs` и `lib/ahp.mjs` и в документах [3. TOPSIS](<../3. TOPSIS.md>) и [4. МАИ](<../4. МАИ.md>).

## Установка

Нужен Node.js 20 или новее.

```text
cd "Фаза 1 - Выбор концепции проекта/Расчёты"
npm install
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run forms` | Создаёт пустой шаблон `Данные/Форма экспертной оценки (шаблон).xlsx` (уже создан; повторять нужно только после изменения критериев или концепций в `lib/config.mjs`) |
| `npm run collect` | Читает `Данные/Ответы/E1.xlsx`, `E2.xlsx`, `E3.xlsx`, сообщает о пропусках и недопустимых значениях и записывает `Данные/topsis_оценки.csv` и `Данные/mai_сравнения.csv`. Ответы не исправляет |
| `npm run status` | Показывает, сколько оценок не хватает каждому эксперту |
| `npm run calc` | Только при полном и корректном наборе ответов трёх экспертов: выполняет TOPSIS и МАИ и записывает `Фаза 1 расчёты TOPSIS и МАИ.xlsx` и `Результаты расчётов.md` |
| `npm run report` | Собирает `Сводный отчёт/Фаза 1 Сводный отчёт.docx` из документов фазы, результатов и трекера. Пока нет расчётов или решения команды, отчёт помечен как «ЧЕРНОВИК» |
| `npm test` | Проверки методов и сквозной прогон на синтетических данных |

## Стадии и файлы

| Файл | Назначение |
|---|---|
| `lib/config.mjs` | Эксперты, концепции, критерии, шкалы, RI. Единый источник для форм, расчётов и отчёта |
| `lib/forms.mjs` | Шаблон формы и чтение заполненных форм |
| `lib/data.mjs` | CSV-файлы исходных данных, проверка полноты и диапазонов |
| `lib/topsis.mjs` | Нечёткий коллективный TOPSIS (тройки, веса, нормирование, расстояния, CC) |
| `lib/ahp.mjs` | МАИ: матрицы, собственный вектор, λmax, CI, CR, геометрическое среднее, синтез, противоречивые пары |
| `lib/workbook.mjs` | Расчётная книга: промежуточные таблицы как формулы Excel и сверка с JS-расчётом |
| `lib/results-md.mjs` | Markdown-таблицы результатов |
| `lib/report.mjs` | Сводный DOCX из Markdown-документов |

**Две независимые реализации.** Расчётная книга содержит формулы Excel (MIN, MEDIAN, MAX, нормирование, расстояния, GEOMEAN, λmax, CI, CR, SUMPRODUCT). Перед записью формулы вычисляются библиотекой HyperFormula, а итоговые CC, приоритеты, ранги и CR сравниваются с расчётом `topsis.mjs` и `ahp.mjs`. При расхождении больше 10⁻⁹ файлы не записываются. Числами в книгу внесены только исходные ответы и собственные векторы МАИ; правильность собственных векторов видна в книге: все λ_i в блоке совпадают.

## Тесты

`npm test` проверяет:

- формирование троек медианой, а не средним; ручной пример TOPSIS (CC = 1 и 1/3); направление критерия затрат; CC ∈ [0; 1]; равные CC при равных оценках;
- отклонение оценок вне 1–9, дробных и неполных наборов, не трёх экспертов;
- пример Саати 3×3 (w, λmax, CR); идеально согласованную матрицу (CR = 0); обратную симметрию геометрического среднего; нормировку весов и глобальных приоритетов; поиск противоречивых пар;
- сквозной путь «пустая форма → заполнение → CSV → расчёт → книга»: на синтетических ответах формулы книги совпадают со скриптом;
- сообщения о незаполненной форме и неверном ID эксперта; ошибки в строках CSV.

Синтетические ответы создаются в памяти и во временной папке ОС. Это не оценки команды, и в `Данные` они не записываются.

## Ограничения

- Вариант TOPSIS — Chen (2000): A+ = (1; 1; 1), A− = (0; 0; 0), вершинное расстояние, веса — тройки важности, делённые на 9. Если методичка курса задаёт другой вариант, его нужно внести в `lib/topsis.mjs`, `lib/workbook.mjs` и документ 3 до расчёта.
- Отображение книги и отчёта в Excel и Word на компьютере, где они создавались, не проверялось: офисных программ там нет. Содержимое проверено чтением файлов и вычислением формул. Перед сдачей откройте файлы в Excel или LibreOffice.
