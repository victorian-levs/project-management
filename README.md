## Расчёты

Нужен Node.js 20+. Один раз выполнить `npm install`, затем:

| Команда | Что делает |
|---|---|
| `npm run phase1:calc` | TOPSIS и МАИ по ответам экспертов, книга Excel с формулами |
| `npm run phase2` | распределение задач фазы 3 (GLPK) |
| `npm run phase4` | прогноз Монте-Карло |
| `npm run phase5` | эвристики расписания |
| `npm run report` | собрать .docx из отчётов .md |
| `npm test` | тесты расчётов фаз 1–2 |

## LLM

Использовалась так, как разрешает задание: в фазе 1 для придумывания концепций и критериев, в фазе 3 для набросков Use Cases, в фазах 2, 4, 5 для помощи с кодом.
