# Проектный менеджмент — команда victorian-levs

Учебный репозиторий по дисциплине «Проектный менеджмент». Сквозной проект проходит пять фаз: выбор концепции, распределение работы, оценка, прогнозирование и планирование. Программный продукт в рамках предмета не разрабатывается; код используется только для учебных расчётов.

Команда хочет работать над **MusicApp** — веб-сервисом поиска и прослушивания музыки с плейлистами и избранным. До расчётов это предпочтительная концепция, а не выбор, сделанный методами. Её сравнивают с тремя альтернативами: Jarvis с локальной базой документов, заявки на ремонт в общежитии, бронирование оборудования студенческого клуба.

## Следующие шаги

1. Встреча 1: проверить концепции, критерии, шкалы и предложенное распределение задач ([P1-02 — P1-04](<Таск трекер/Задачи.md>)).
2. Спросить преподавателя, допустимы ли автоматические расчёты и какой вариант методов требуется ([P1-11](<Таск трекер/Задачи.md>)).
3. Проверить форму и заполнить её каждому участнику независимо ([P1-06 — P1-10](<Таск трекер/Задачи.md>)).
4. Начать вести [журнал работы](<Таск трекер/Журнал работы.csv>): периоды и чистое время задач обязательны по заданию.

## Использование LLM

Задание разрешает LLM так, как указано для каждой фазы. В фазе 1 — для придумывания концепций и критериев. Черновики концепций, критериев, форм, документов, трекера и расчётного инструмента подготовлены с помощью LLM и помечены как черновики до проверки командой. Экспертные оценки, встречи, решения и отработанные часы LLM не заполняет.
